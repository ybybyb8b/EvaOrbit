## 验证记录

- 完整自动回归只运行一次：656 项，642 通过、2 失败、12 项可选数据库环境跳过。一路失败是原 Cats 测试在 Windows sandbox 临时目录中 rename 的 EPERM，另一路是新增 Tracker DELETE 白名单后的旧断言；使用项目 tmp 并修正断言后，相关 9 项定向复验通过。未重复全量回归。
- 新增 5 项存储账户测试：允许的测试账号可读自身存储路径；未知账号不接触 Storage。新增隔离 SQLite 聚合测试验证图片元数据存在但文件缺失时，四个模块仍可读。
- 七模块合成数据浏览器在 390/402/1280 宽度检查通过；用药多段说明不重叠。Weight / Period / Medication dose 候选在故意延迟业务 HTTP 的场景不发起该请求，打开表单检查通过。只代表本地浏览器，不宣称真机耗时。
- Tracker 独立副本浏览器：离线增改删与重启、丢回复幂等、冲突、远端删除、暂停、旧队列保留，以及带确认的整个 Tracker 在线删除通过；无关 Tracker 的待处理草稿保留。旧脚本输入时序曾出现一次备注等待超时，改为等待表单入场完成再填写后通过。
- Food 导航专项通过：记录/饮品内页 header Back、Places 内页侧栏重选后回总览。原 Food 全量只读阶段脚本仍使用旧 View 标签及禁用保存断言，不用于证明新在线业务全部验收；本次仅运行其导航专项分支。
- lint、TypeScript、本地 React 资源构建及 Next Web 构建通过。新包 XCTest 和 iPhone 验收尚未运行；新增 Native 白名单断言待 macOS CI。

## 数据与同步统一入口

Web 与本地共用 SyncManager 和 14 板块能力目录。进入本地管理页仅读取当前账户缓存，不隐式联网补账；手动更新单项或全部时复用既有受账户约束的平台接口。Home 更新包含日/月/提醒，全部更新每批最多两个业务板块，重复触发被合并，失败保留旧数据并逐项显示错误。账户切换/卸载页面后不再把异步结果写入界面。Tracker 使用原独立编辑副本，旧队列不参与。

能力边界仍为 Tracker 离线编辑/双向同步，其余模块在线保存/下载后离线查看。统一入口不是新同步协议；完整离线写入仍需逐类实现版本、幂等回执、关联 ID 与业务事务，尚未因管理页完成而开放。此次没有生产迁移、API 发布或 Native 权限/签名变化。

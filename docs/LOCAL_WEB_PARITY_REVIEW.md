# 本地开发版与 Web 对照（2026-10-21）

## 基线与验证边界

- 线上源码基线为已发布的 main `43dfca3a7ff9fc20a256abdb945121f33f45876b`；本轮 fetch 后 main 未增加提交。开发版基于 `8e475a0` 加本次待发布修改，不合并 main。
- 对照三者：当前线上源码、开发分支里的 Web、同分支本地包。后两者共享组件，不代表这些组件的新版本已经上线。
- 实际打开正式站公共登录页，在 402 / 1280 视口与本地包比较；没有登录真实账户、提交生产表单或改线上数据。业务页面用独立 SQLite 合成数据、模拟 HTTP 和 Native Bridge 验证。
- 浏览器及源码检查不替代 WKWebView/iPhone 16 Pro 的安全区、键盘、原生启动、签名和系统权限验收。

## 本轮修正

1. Tracker 的云图标和 Settings 使用同一会话状态及同步任务，保留比较双方内容、取消替换、明确采用远端/保留本地的处理方式。
2. Universal Log 的菜单定义与业务表单复用；Tracker 选择项补齐可访问名称。尚未获得云端版本的 Tracker 可预览表单，但不能保存。
3. 修正 Tracker 部分字段更新（例如只改备注）入队时丢失父引用的问题；保留版本、CAS、冻结 wire 和幂等回执保护。
4. 日历规则表单不再等待完整图标目录才显示；本地图标未就绪时显示加载状态，禁止回落到线上 `/api/reicon`；目录文件并行读取，加载失败保留重试入口。
5. 同步验收脚本改用云图标；修正菜单数量、焦点循环、只读模式及快照准备等过时的浏览器断言，没有放宽业务写入限制。

- 13 组现有模块浏览器验收均完成：Home、Food、Cats、Subscriptions、Chronicle、Memo、Inbox、Health、Relations、Media、Workspaces、Settings、Appearance。首次发现的失败只重跑受影响组。

- 本轮全量共 651 项：初次 636 通过、12 项可选数据库环境跳过、3 项失败；3 项分别为过时 Home 源码断言、Tracker 部分更新依赖和 Windows 临时目录头像改名权限。源码/队列修正及工作区临时目录复验后，相关 16 项全部通过；未重复运行整套测试来掩盖初次失败。

## 打包后最小真机核对

覆盖安装独立开发版，保留正式 EO 和现有 SQLite/队列，不要卸载清库。先看启动、原数据与 Tracker 云图标；再测记录保存/重启/断网恢复、Settings、日历图标、各模块表单的键盘与返回。浏览器已检查的数据保护不应替代这一步。

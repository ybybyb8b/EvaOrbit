# Apple 数据读取范围与分批续传

## 日期口径

所有新读取并参与同步的 Apple 数据以下表为准；没有永久上界，不是从 10 月 1 日起只同步 365 天。已有 EO 记录和关联不因范围收窄而删除。

| 数据 | 2026-10-01 下界判断 |
| --- | --- |
| Calendar | 事件开始日期，按事件时区；无时区用设备时区 |
| Reminder | 有到期日期按到期日期；已完成项目也可由完成日期满足；无到期日期按创建日期，未知创建日期不猜测 |
| Sleep | 按醒来日期，保留前一晚跨午夜的完整睡眠片段 |
| 其余 HealthKit 样本 | 样本发生／开始日期，优先样本时区，否则设备时区 |

Calendar 的 EventKit 查询必须有有限区间。每一轮都扫描今天前三天到未来两周的近期窗口；补充发现同时从 2026-10-01 起按季度向未来分页。季度仅是单次读取大小，不是同步截止日期。首段查询覆盖全球最早的 10 月 1 日，再按对象时区过滤。恢复身份仍检查完整候选以识别歧义；范围外只返回 `out_of_scope`，不把它误当成删除。

HealthKit 首次升级范围时仅重置查询 anchor，并更新读取 epoch；已有样本、业务记录及全部待提交队列保留。重新读取继续使用样本 UUID 幂等处理。睡眠查询保留既有前夜缓冲，聚合继续按醒来日期过滤。无需新增权限或更改授权设置。

## 同步执行

- 完整分页获取云端关联身份，防止未核对的旧对象被误导入成新记录。近期对象与未完成 Reminder 优先；单轮最多检查 32 个近期关联，手动轮再加最多 8 个、维护轮最多 16 个历史关联。
- Calendar 旧身份恢复最多 4 条并行，Reminder 和可能写入 Apple 的动作维持顺序。近期与历史恢复循环各有 4 秒协作预算，在批次边界让出；已启动的请求必须等到结果，不能据此保证整轮在 8 秒内结束。实际关联核对同样对近期／历史各保留 4 秒协作预算；新建发现使用独立 4 秒预算，单轮最多 32 条、维护轮最多 16 条。所有阶段都只在开始下一个对象前让出，当前写入等待真实结果，不中断或重放；预算让出的对象保持待处理而非失败退避。
- 只有已解决项才保存完成指纹；未解决项保存按项退避时间和次数。旧版断点不再用于跳过关联。内容指纹和季度游标保存到设备 localStorage，按账户、安装、同步范围与来源隔离；只存摘要哈希和执行元数据，不复制标题正文。来源、路由或内容变化会重新核对。存储不可用时依赖已确认的云端绑定，进度可能重做，不降低身份检查。
- 手动与自动共用按类型编排，单项失败／权限撤销不阻断另一项，部分成功不更新全局成功时间。手动按钮优先完成近期并检查少量历史；既有前台维护器在 App 打开且联网时分批继续。离开前台暂停，不承诺 iOS 持续后台执行。安全屏障、权限不足、歧义和结果不明仍会暂停对应类型的新建。
- 进度明确显示本轮处理与仍待核对的关联／新内容；轮次时间不代表所有历史和未来内容已经检查完。完成一轮历史发现后仍继续向未来分页；定期从下界重新检查，保留既有去重身份。

同一次 `native.api` 内复用已验证的账户授权，仍检查账户、generation、在线开关及服务端认证，不跨请求缓存权限。Reminder 原子导入需要下述配套迁移；没有新增 Bridge 方法、系统权限或业务离线写队列。Native 修改需新 IPA；Windows 的模拟回归不代替 macOS Swift 编译、XCTest 和 iPhone 16 Pro 验收。

## 服务端与 Native 配套

`GET /api/eventkit/records?kind=task|reminder&afterId=...&limit=500` 按 ID 完整分页；Task 通知规则也批量分页组装，避免业务列表返回上限与逐 Task 读取。`POST /api/eventkit/reminder-import` 调用 `202610280001_eventkit_reminder_import.sql` 的事务 RPC，同时建立 Task 和账户关联；失败回滚、提交后重试与重装复用 ID，保留已有基线、拒绝孤儿及歧义身份，不自动清理历史重复。新接口不可用时明确失败，不回退到旧多步创建。2026-10-28 已在生产库预演并回滚后正式应用，迁移登记与函数权限已核验；本次事务内已有业务表指纹未变。

恢复请求的可选 `recoveryBatch` 只用于 Native 内存索引复用；同一轮标记查询复用完整 Reminder 身份索引，系统存储变化、App 写入、批次变化或最长 60 秒使索引失效／释放。保留多候选检查与未选择列表保护；旧 Host 忽略附加参数时继续原恢复行为。无新 Bridge 方法、权限或 entitlement。

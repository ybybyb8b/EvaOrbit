# Parlor Native 独立测试版

分支：`codex/parlor-native-test`。基于 `74d4a0f`，包含 Native Eva Phase 1A、Parlor / Sebastian V1 及 Hermes 退役清理。仅推送测试分支；不合并 main，不更改 Web 构建分支，不部署 API，不执行生产迁移。

## 发布与安装边界

- `vercel.json` 禁用该分支部署；iOS workflow 对该分支忽略 push，手动使用 `local_trackers=true` 构建，避免生成普通线上 Host。
- 保留 `com.evaorbit.nativehost.trackerspoc`、`evaorbit-trackers-poc`、HealthKit entitlement 和现有 ad-hoc → audited patched xtool → Personal Team 重签安装链。安装前确认包为本地版，按现有安装说明覆盖安装，保留设备数据；不要为测试先卸载旧 App。
- 构建成功后，在对应 Actions 运行产物下载 `EvaOrbitHost-ad-hoc.ipa`。该产物仍须按现有流程重签后安装；构建成功不等于已经安装或通过真机测试。
- 用户授权后触发 CI；本地没有 Swift/Xcode，不伪造编译或 Swift Testing 通过结果。workflow 沿用现有决定，不执行 Simulator／Swift Testing，原生行为由用户在 iPhone 16 Pro 验收。

## 清理与保留

已移除仓库内 Hermes 平台插件、电脑聊天与配对 / 命令 / 回执 / 轮询 UI、连接 API、Bark 回调、通知载荷、代理例外及本地 business.request 白名单。首页悬浮球只读本机 AI 状态；旧 Host 提示升级，不再尝试电脑连接。Home 纸条只保留既有 Inbox 保存，不伪装为 Native 聊天或执行任务。

保留共用 Markdown、输入、滚动、气泡尾巴、分段气泡、头像和背景。共用模块改名为 `parlor-*`。原 IndexedDB / localStorage 名称仅作为设备外观格式保留，避免偏好丢失，不连接 Hermes。没有删除服务端历史表、已应用迁移或其他业务数据；不自动导入旧聊天与服务端密钥。

## 先做这些测试

建议按顺序执行。下面涉及聊天、停止和错误测试的操作可能产生真实模型费用，由用户在自己的服务商账户执行；不需要把 API Key 发到聊天中。

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 安装与入口 | 覆盖安装本地测试包，登录，点击首页悬浮球 | 直接进入 Parlor，左上 Sebastian；无 Hermes 配对、等待电脑上线或旧连接请求 |
| 其他模块回归 | 打开 Home、Task、Tracker、Settings，查看旧数据与现有同步状态 | 旧数据保留，原有业务入口和返回正常；不要用删除数据验证 |
| 初次配置 | 右上设置 → Providers & Models；填写 HTTPS API Base URL、API Key、准确的文本 Model ID | 能保存；保存本身不测试连接、不请求模型。不要填写网页聊天地址；不是所有服务商都兼容 `chat/completions` SSE |
| 首次聊天 | 发送一条简短中文问题 | 文本逐步出现，不等完整回答结束一次性显示；Sebastian 风格自然，没有假称完成 EO 操作 |
| 分段气泡 | 设置 → Data & Privacy → 聊天外观与头像，开启自动分段气泡；让模型回答多个段落 | 段落 / Markdown 内容块拆成气泡；返回和重开仍保留开关 |
| 外观与键盘 | 浅色 / 深色；上传测试头像；打开键盘、输入中文、换行、发送、滚动旧消息 | 无横向溢出、安全区遮挡、重复发送或输入法中断；向上阅读时不被强制拉回底部 |
| 停止生成 | 请求稍长回答，看到文字后点停止 | 输出停止，部分内容保留，按钮恢复可发送；不自动重试。取消不保证服务商立即停止计费 |
| 恢复历史 | 完成一条回答后杀掉 App，再打开 Parlor | 原会话与完整消息仍在；历史 / 新建 / 返回可用 |
| 中断恢复 | 生成途中杀掉 App，再打开 | 已显示的部分内容保留并标为中断；不会自动续发计费请求 |
| 前后台与断网 | 生成中切后台；另一次生成中断网再恢复 | 正确停止 / 中断或报错，保留已收到内容；恢复网络不会自动重复模型请求 |
| 密钥持久化 | 退出重开后发送简短问题；再主动移除该 Provider 的 Key | 重开可继续请求；移除后发送被阻止，不偷偷使用云端旧 Key |
| 错误恢复 | 临时保存无效测试 Key，手动发送一次，再换回有效 Key | 展示可理解错误，无自动重试；恢复有效 Key 后可手动正常发送；错误不回显密钥 |
| Persona | 修改名称、称呼、风格、提示词或默认模型；重开 | 设置保留，新回答使用新配置；历史回答的人格署名不改变；保存不额外请求模型 |
| 模型被停用 | 绑定一个模型后停用 / 删除它 | 提示重新选择，不能静默改用其他服务商或模型 |
| 用量 | 点回答下方模型 / Token / 时间小字，对照服务商后台 | 输入输出能获取则记录；缺失值与价格保持未知，不冒充 0；每次用户发送只有一个主请求 |
| 账户隔离 | 如有第二个已授权 EO 账户，切换后检查本机聊天 / 配置 | 看不到前一个账户的会话、人格和 Key；切回后原数据仍在。没有第二账户则记未测 |

## 本版明确限制

当前是文本聊天：只有一个全局活动生成任务；不支持图片、音频、自动记忆、群聊、EO 工具或后台持续生成。聊天不能实际查询或修改日程、任务、Memo / Graph。人格权限不能靠提示词扩大。

没有自动上下文压缩与独立 AI 备份恢复；上下文过大时需要新会话。历史列表显示最近 200 段。建议先用普通测试内容，不把重要资料仅存在这份测试 App 中。Provider 的 usage / `stream_options` 兼容性必须由实际服务商验证，不自动重试可能已经计费的请求。

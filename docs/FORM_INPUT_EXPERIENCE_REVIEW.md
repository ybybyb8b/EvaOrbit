# EO Sheet 全局填写体验审阅

审阅日期：2026-10-03。基于当前工作区代码，覆盖业务记录、新增与编辑入口、关联选择及设置表单。未读取生产数据，未进行 iPhone 真机操作；下述频率和数量阈值是设计起点，不是实际使用统计。本轮只添加审阅文档。

## 结论与选择规则

适合全局统一的是填写规则，而不是把所有 input 自动替换成 select。

- 重复使用的短文字：可输入的历史候选列表，保留新值；候选多时可搜索。
- 当前字段的少量常用值：底部胶囊快捷填入，通常 3–5 个，加“更多”。
- 有独立身份的对象：实体选择器，按 ID 保存，显示名称与区分信息；不可用同名文字替代关联。
- 固定枚举：少量短选项可以直接分段或胶囊选择；较多或较长的选项保留下拉。
- 正文、原因、描述、个性化名称：自由输入。数字、金额和测量值也不应从历史自动猜填。

历史候选与底部胶囊可共用数据：胶囊提供快捷入口，候选列表提供完整查找。它们不是每个字段都必须同时出现的两层 UI。

## 手填字段决策矩阵

“开放候选”表示既能选已有值，也能继续输入；不收紧原有字符串存储。“胶囊”指当前字段的快捷推荐，不表示直接提交记录。

| 模块与字段 | 推荐交互 | 胶囊与上下文 | 搜索 |
| --- | --- | --- | --- |
| 饮品名称 | 开放历史候选 | 当前品牌/类型/店铺下最近常喝 | 历史较多时需要 |
| 饮品品牌 | 开放历史候选 | 最近、常用品牌 | 较多时需要 |
| 饮食“吃了什么” | 保留自由标题；历史餐食入口可作为后续增强 | 同场景常用标题；选菜品自动生成标题的现有保护逻辑保留 | 选菜品时搜索，标题本身不强制变选择器 |
| 食品库品牌 | 开放历史候选 | 同类食品常用品牌 | 较多时需要 |
| 食品库默认份量 | 自由输入 + 胶囊 | 本食品/同参考类型的历史份量；单位必须明确 | 通常不需要 |
| 店铺城市 | 开放历史候选 | 最近常用城市；不默认请求定位 | 较多时需要 |
| 店铺地点 | 自由输入 + 城市内历史候选 | 同城市的商圈、街道；完整地址不宜塞成长胶囊 | 较多时需要 |
| 店铺品类、菜品品类 | 开放历史候选 | 常用类别，菜品优先当前店铺 | 较多时需要 |
| 店铺名称、分店、菜名 | 创建时自由输入，可提供重名提示 | 不从历史自动创建重复实体 | 关联现有对象时搜索 |
| 训练老师、课程 | 开放历史候选 | 老师与课程相互收窄；提供可撤销的组合预设 | 较多时需要 |
| 健康症状/疾病标题 | 自由输入 + 同记录类型历史建议 | 只复用用户已有表述，不推断病情 | 历史较多时可搜索 |
| 健康严重程度、身体部位 | 开放候选 + 少量胶囊 | “轻/中/重”等可点击但仍允许自填；部位按记录类型 | 部位较多时可搜索 |
| 健康就诊机构/医生、猫咪诊所/医生 | 开放历史候选 | 医生优先当前机构，猫咪与本人分开 | 较多时需要 |
| 健康药物标题、猫咪药名 | 开放历史候选 | 只推荐名称，不联动当次剂量/频率 | 较多时需要 |
| 健康/猫咪频率文字 | 保留自由输入，可复用同药物历史文字 | 点击确认；不把文字自动转换成提醒间隔 | 通常不需要 |
| 健康测量单位、猫咪单位/测量类型、观测数值字段单位 | 开放候选 + 胶囊 | 按测量类型展示历史单位，不能自动换算既有数值 | 通常不需要 |
| 猫咪护理标题、例行事项名称 | 自由输入 + 少量操作模板 | 当前护理类型的模板，明确只是填写标题 | 通常不需要 |
| 猫粮品牌、口味/配方、购买渠道 | 开放历史候选 | 按品牌/食品类别推荐口味；渠道用常购历史 | 较多时需要 |
| 记忆分类 | 合并固定分类与完整历史的开放候选 | 最近/常用分类 | 较多时需要 |
| 任务标签、Memo 标签、日记标签、案底触发场景 | 多选标签输入，允许创建新标签 | 点击追加；已选可移除；按模块取历史 | 较多时需要 |
| 项目事项模块 | 当前项目内开放历史候选 | 当前项目常用模块 | 较多时需要 |
| 项目事项优先级 | 开放候选 + 胶囊 | 当前项目已有写法；现有字段是字符串，兼容 P1、High 等 | 通常不需要 |
| 观测分组 | 开放历史候选 | 已有分组 | 较多时需要 |
| 观测自定义 text 字段 | 默认自由输入，明确启用历史建议后增强 | 只在同 tracker、同 field key 内取值 | 开启且历史较多时需要 |
| 观测选项配置 | 可添加/删除的选项列表 | 不从其他观测混入选项；保留粘贴逗号文本导入能力 | 配置阶段一般不需要 |
| 关系称谓 | 延续已有历史胶囊 + 开放候选 | 朋友、同事等实际使用过的称谓 | 较多时需要 |
| 订阅币种、支付币种 | 常用代码胶囊 + 可输入的币种候选 | 优先已有币种，显示代码与名称；保持现有三字母代码输入能力 | 提供完整目录时需要 |
| AI Model ID | 可输入的已发现模型候选 | 优先本 Provider 已发现模型，不建议静态写死型号 | 需要；匹配完整 ID |
| 日历规则标题前缀 | 自由输入，单条事件入口可填入待确认前缀 | 不从其他规则猜填；匹配规则会改变归类语义 | 不需要 |

不适合历史下拉或通用推荐：人物/猫咪/项目/订阅/观测的创建名称与昵称，影视原创标题/译名/季标题，任务内容，Inbox、今日一记、日记、Chronicle、Memo、记忆正文，备注、喜好/禁忌、诊断、处方、检查结果、原因、下一步、解决说明，以及 API Key、URL、账号字段。名字创建可做重名提示，但不将其当作选择既有实体。

剂量、金额、热量、测量结果不自动从历史填入。训练时长可以提供明确单位的少量快捷值；不默认覆盖已输入时长。

## 哪些既有下拉应有搜索

| 对象 | 建议 | 匹配与展示 |
| --- | --- | --- |
| 店铺、门店、菜品 | 已有搜索，继续完善 | 店名/城市/地点/门店，菜名/品类；保留 ID 与已选对象 |
| 猫粮购买“买的是” | 优先添加 | 食品名称、品牌、口味 |
| 影视系列/母作品 | 优先添加 | 系列名称，按作品类型分组；保留“新建系列” |
| AI 会话模型、发现模型 | 添加 | Provider、显示名、完整 Model ID；不可用的已选值仍可辨识 |
| 关系事件参与人 | 虽为复选列表，也应添加搜索 | 名称、昵称；已选保持可见，不因搜索消失 |
| 观测 single_select / multi_select | 随选项数增长添加 | 同属性选项；多选显示已选项与完成入口 |
| 记忆分类、历史老师/课程/品牌等 | 候选数增长时添加 | 开放候选；保留手动输入 |
| 日历语义分类、Apple 提醒路由列表 | 随数量增长添加 | 分类名称，路由列表名称与来源信息 |
| 关联经期 | 较长历史需要 | 以日期区间为主要标识；“最近几次 + 更多”通常比文字搜索更自然 |
| 猫咪/家庭对象 | 通常不需要 | 数量少时直列；大量对象时再添加 |

建议起始阈值：不超过 5 个短枚举可直列；6–10 个可普通下拉；超过 10 个，或无法在一屏辨认时加搜索。实体库通常一开始就预留搜索入口。不要把阈值当成硬限制，名称长度、分组与任务频率同样重要。

不需要搜索的现有枚举：饮品类型/糖度/冷热/评价、餐次/场景/评价、训练类型、任务优先级、常见状态、性别/亲密度、订阅周期/提醒提前量、食品类别/参考类型/数据来源、健康状态、案底错误类型/严重程度/状态、项目事项类型/状态、观测字段类型/评分/目标运算符/周期、AI 协议/回复长度/主动程度等。选项固定且少，加搜索只会多一步。

关系事件的 13 种“发生了什么”适合先按消费、礼物、往来、互动分组，并提供常用动作；比默认弹键盘搜索更合适。

Memo 详情中的“合并目标 ID”是另一类问题：建议用搜索选择目标 Memo，提交仍保存 ID，替代要求用户记住数字 ID。

## 底部胶囊与 Sheet 行为

1. 推荐区在 Sheet 底部操作区上方，处于同一布局；键盘弹起时跟随可视区域，不使用固定设备偏移。
2. 只显示当前聚焦字段的 3–5 个短候选，配字段名；支持横向滚动与“更多”，正文/密码/无候选字段不显示。
3. 单值点击替换当前字段；标签点击追加且去重；多选点击切换。长文本留在候选列表，不强行压成短胶囊。
4. 点击推荐不提交表单，也不把键盘收起再弹出。建议支持一次撤销；中文输入法组合输入期间不抢选或覆盖内容。
5. 可选字段始终有清空/未填写；必填项不自动选第一个，未知时间仍允许日期-only。
6. 组合预设与单字段推荐分开。训练组合卡移到主要字段之前或提供紧凑入口；说明会改哪些字段，保护日期、当次备注和已有手填内容，允许撤销。
7. 手机长列表在当前 Sheet 内进入选择子视图，保留表单草稿与滚动位置；不叠加第二层 Sheet。短列表可就地展开。
8. 搜索列表提供加载、加载失败与重试、无结果、清空；开放文字可“使用当前输入”，实体关联不能偷偷新建对象。
9. 桌面允许正常键盘导航；Escape 先关闭候选，再关闭 Sheet。无障碍语义随具体控件实现，不能只依赖视觉高亮。
10. 提交错误显示到对应字段并滚动到首个错误；关闭有修改草稿时提供保留/放弃选择，保存失败保持输入。

现有 FormSheet 已有 viewport 与焦点基础。本轮没有证据认定其真机键盘表现有故障；以上新增行为必须在 iPhone 16 Pro 的 Safari/PWA 与实际宿主中验证。

## 历史数据与边界

- 按业务明确接入字段，不根据 label 或 input type 做全局 DOM 自动推断。
- 从成功保存的记录取候选；不把未提交草稿、搜索词当成历史。
- 候选去空和去重，限制长度；比较时可规范化空白/大小写，写入时保留用户原值，不批量清洗旧数据。
- 当前用户/业务域隔离；观测按 tracker + field key、项目按 project、医生按机构、地点按城市过滤。
- “最近”与“常用”分开考虑。补记的记录日期与最近录入时间不同，应先确定排序语义。现有 buildHistorySuggestions 按频次优先；训练组合已采用时间衰减，可作为第二阶段参考。
- 保留完整搜索渠道。30 个建议或 200 个店铺切片只能做快捷候选，不代表全部历史；不能只从当前筛选页面抽样后宣称完整。
- 编辑时已选实体和旧文字始终可显示，不因归档、候选截断或搜索条件而丢失。
- 字符串候选、固定枚举、实体 ID 各守原存储语义。币种目录、优先级标准化、观测 text 改 select 都不能顺带收紧旧值或改类型。
- 首期无需新增字典表、AI 推荐或拼音搜索依赖。先复用历史工具与明确的字段上下文；规模和使用反馈证明有需要再扩展。

## 建议实施顺序

**第一批：高频、低风险。** 补记忆自定义分类；饮品/训练的历史胶囊与候选入口；训练组合预设前置并防覆盖；标签改多选输入；地点按城市推荐；猫粮与影视系列选择增加搜索。

**第二批：补全重复短文字。** 猫粮品牌/口味/渠道、项目模块、观测分组、机构/医生、单位、关系称谓与币种，统一当前字段底部推荐区；补实体选择加载和失败状态。

**第三批：复杂表单改善。** 按字段展开选填详情；关系事件参与人搜索与金额明细逐行录入，保留粘贴入口；Memo 合并目标改实体搜索；观测选项多时搜索；补草稿关闭保护与首个错误定位。

不应先把所有 select 重写或把所有文字字段接入历史。先完成饮品和训练两条高频流程，验证点击次数、滚动量、键盘切换次数，再扩大覆盖。

## 验证范围

初始审阅为代码静态审阅。用户授权后已实施下面的表单改进，并补充交互验证和项目检查。

实施时应覆盖：新建/编辑/主页快速记录一致；无历史和大量历史；重复/长名称；候选加载失败仍能手填；中文输入法；多选不丢失；推荐不误提交/不覆盖草稿；日期-only 往返；翻译标签不改变实际值；iPhone 安全区、键盘切换、横竖屏与关闭后的焦点返回。

## 实施结果

- 开放短文字统一采用可自由输入的历史推荐控件：饮品名称/品牌、训练老师/课程、记忆分类、地点/城市/品类、猫粮品牌/口味/购买渠道、项目模块/优先级、观测分组、关系称谓、常用币种、食品品牌/份量、部分健康与猫咪记录字段、发现的模型 ID。聚焦时 Sheet 底部显示最多五个胶囊，支持更多候选、独立搜索及单次撤销。
- 标签及触发场景改为可追加、移除的胶囊；支持中英文逗号、回车和去重，未按回车的文字仍随表单提交。
- 猫粮关联、影视系列、AI 会话模型、Memo 合并目标改为名称搜索选择，仍保存原有 ID。参与人和观测多选保留已选项；观测单选、日历语义分类、经期关联、服药预设和 Apple Reminder 路由在选项超过十个时提供搜索。
- 店铺/菜品保留远程搜索，补加载、失败、重试及多选完成入口。食品关联和城市/机构上下文维持原业务范围。
- 训练组合预设前置，替换已有训练字段前确认，日期/备注保留并可撤销。关系事件按消费、礼物、往来、互动分组；金额明细逐行输入，仍支持原粘贴格式和金额校验。健康选填详情折叠展示。
